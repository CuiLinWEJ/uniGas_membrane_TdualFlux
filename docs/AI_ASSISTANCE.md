# AI Assistance Statement

## Purpose

This document describes how generative artificial intelligence (AI) was used during the development of this repository.

The purpose of this statement is to provide transparency regarding the development process while clearly distinguishing AI-assisted activities from the repository maintainer's original technical contributions.

---

# Scope of AI Assistance

Generative AI (ChatGPT) was used as a software development assistance tool during the post-thesis development stage.

Typical uses included:

* technical discussion;
* debugging suggestions;
* code review;
* alternative implementation ideas;
* documentation drafting;
* explanation of programming concepts.

AI was used as an interactive assistant rather than an autonomous software developer.

---

# Human Contributions

The repository maintainer independently performed:

* identification of implementation issues;
* definition of technical objectives;
* evaluation of alternative approaches;
* source-code modification;
* software integration;
* compilation;
* numerical simulations;
* debugging;
* verification of simulation results;
* evaluation of physical consistency;
* final implementation decisions;
* repository organization and documentation.

All source code included in this repository has been reviewed by the maintainer before publication.

---

# Development Workflow

The typical development process followed these steps:

1. Identify an implementation or numerical issue.
2. Investigate the underlying physical or programming problem.
3. Discuss possible approaches using ChatGPT.
4. Select an appropriate solution.
5. Modify the source code.
6. Compile the software.
7. Execute numerical simulations.
8. Evaluate the simulation results.
9. Refine the implementation when necessary.

This iterative process was repeated throughout development until satisfactory numerical behaviour was obtained for the available validation cases.

---

# Responsibility

The repository maintainer is responsible for:

* the design choices adopted in this implementation;
* the correctness of the published source code;
* numerical testing and verification;
* documentation;
* future maintenance of the repository.

AI-generated suggestions were treated as technical recommendations and were accepted, modified, or rejected based on the maintainer's evaluation.

---

# Limitations

The use of AI does not imply that generated suggestions are automatically correct.

All published code should be regarded as the result of human review, implementation, and verification.

Users are encouraged to independently validate the implementation before applying it to scientific or engineering studies.

---

# Version

This statement applies to the current public version of this repository and may be updated as the project evolves.
